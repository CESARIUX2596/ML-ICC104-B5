# Lab U1_L2: Bayesian Inference & Model Selection

Read the **Lab U1_L2 Instructions PDF** before starting. It explains the required tasks, short answers, and submission process.

## Get the starter notebook

1. Sync your fork with the course repository, or pull the latest changes if your local copy is already up to date.
2. Locate `ML_U1_C5_Lab_skeleton.ipynb`.
3. Copy it into your own folder and rename it exactly as:

```text
Students/<YourStudentID>/Laboratories/U1_L2.ipynb
```

4. Complete every `# TODO` cell and write your short answers in Markdown cells.
5. Before committing, select **Kernel -> Restart & Run All** to confirm that the notebook runs from top to bottom without errors.
6. Commit and push only your completed notebook, then open a pull request titled:

```text
<Your Name> <YourStudentID> - Lab U1_L2
```

Use `ML_U1_C4_Examples.ipynb` and `ML_U1_C5_Examples.ipynb` as references. Do not edit the starter notebook in place; always work in your copy inside your student folder.
